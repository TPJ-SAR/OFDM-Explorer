Time domain: each subcarrier over one OFDM symbol

Subcarrier k has frequency fk = k·Δf, so it fits exactly k whole cycles in τS. Its starting phase comes from the data symbol it carries (right-hand labels).

Time domain: composite OFDM symbol (sum of all subcarriers)

This is the real part of the IFFT output, x(t) = Σ Xk·ej2πfkt. Notice the tall peaks compared with the RMS level: that is OFDM's high PAPR.

Frequency domain: overlapping sinc spectra

Each subcarrier's spectrum is a sinc centred on fk, with nulls every Δf. Dashed lines are where the receiver's FFT samples. With ε = 0, every peak sits on the other subcarriers' nulls, so there is no guard band and no interference. Move ε and the coloured dots show the leakage (ICI).

Time domain: the echo vs the cyclic prefix

Each colour is one OFDM symbol: the darker slice is the CP (a copy of the symbol's tail). The receiver throws the CP away and FFTs only the 3.2 µs between the dashed lines. The echo is the same stream shifted by τ. While τ ≤ TCP, the previous symbol's echo dies out inside the CP. Once τ > TCP, it spills into the FFT window (red hatching) → ISI.

Received constellation (after FFT)

Each dot is one subcarrier of one symbol, coloured by subcarrier (red = lowest, violet = highest). + marks the ideal points. Clean clusters = perfect recovery.

Channel response: frequency-selective fading

The echo adds constructively at some frequencies and destructively at others. Each stem is the gain Hk one subcarrier sees. OFDM handles this because each narrow subcarrier only needs a single complex correction, which is the one-tap equalizer.
